learn-lean applets

Three things that are hard to see from inside a text editor, made visible. Each one pairs with a chapter — read the chapter, then come play here (or the other way round; both work).

⟶
Ch. 2 – 3

The Reduction Machine

Step through a recursive function as it unfolds, one rewrite at a time. Then race naive reverse against the accumulator version and watch n² pull away from n.
≅
Ch. 6

Proofs Are Programs

A miniature proof assistant. Click term constructors to build a proof of a proposition, and watch the goal shrink. Solve one and it hands you Lean code you can paste straight into the chapter.
⊢
Ch. 7

Reading the Goal State

Four real proofs, stepped through tactic by tactic, with the goal state captured from Lean itself. New hypotheses in green, changed goals in amber.

How to use these

Open them straight from disk — no server needed: 

open applets/index.html

They are single self-contained HTML files with no dependencies, so they work offline and will keep working. If you want to poke at how they're built, the JavaScript is right there in the file — the reduction machine in particular is a real (tiny) term rewriter, about 60 lines.
